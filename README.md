# IziBox (macOS)

**IziBox** — личное PWA-приложение «сообщения и дела в одном окне». Локальное и приватное: все данные хранятся на вашем Mac в зашифрованном SQLite, ничего не уходит в облако.

Объединяет Telegram и Email в один inbox, ведёт контакты с типами и папками, управляет задачами и календарём, напоминает о делах и днях рождения.

## Возможности

- **Входящие** — сообщения из Telegram и Email в одном inbox; папки, каналы, типы контактов, спам.
- **Контакты** — типы (личные / сервисные / спам / прочее), папки, заметки, дни рождения, объединение дублей.
- **Задачи** — канбан (новые / в работе / выполнено), дедлайны, напоминания, повторяющиеся задачи.
- **Календарь** — задачи, события и дни рождения; виды месяц / неделя / день.
- **Напоминания** — фоновый scheduler по задачам.
- **Безопасность** — локальные данные (SQLite + Fernet-шифрование).
- **Бэкап** — экспорт/импорт всех данных одним файлом.
- **PWA** — работает офлайн, устанавливается на телефон.

Подробное описание всех разделов — в [руководстве пользователя](docs/user-guide.md).

## Установка (macOS, Apple Silicon)

> Версия для Mac на чипах Apple Silicon (M1 / M2 / M3 / M4). Python уже включён в папку — **устанавливать Python и Node.js не нужно**.

### Шаг 1. Скачайте и распакуйте

1. Нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте архив в удобное место (например, в папку `Documents`). Получится папка `IziBox-Mac`.

### Шаг 2. Запустите

1. Откройте папку `IziBox-Mac` → `backend`.
2. Дважды кликните файл **`run_macos.command`**.

Откроется окно Terminal: приложение проверит Python, при первом запуске установит зависимости (нужен интернет, занимает 1–3 минуты) и запустит сервер. Затем **само откроется браузер** с интерфейсом по адресу `http://localhost:7911`.

### Если macOS не даёт открыть файл

macOS может заблокировать неподписанный скрипт. В этом случае:

1. **Правый клик** по `run_macos.command` → выберите **«Открыть»** → в диалоге снова **«Открыть»**.
2. Либо: **System Settings → Privacy & Security** → внизу нажмите **«Open Anyway»**.

После этого файл будет запускаться обычным двойным кликом.

### Первый запуск и онбординг

При первом открытии появится мастер настройки:

1. **Telegram** — введите логин (любое имя) и, при желании, номер телефона.
2. **Email** — адрес, пароль, серверы IMAP/SMTP.
3. **Прокси** — при необходимости (например, для Telegram).
4. **Готово** — проверьте данные и завершите.

Логин можно ввести, а каналы подключить позже в разделе «Каналы». Шаги можно пропустить.

## Как остановить / перезапустить

- Чтобы **остановить**: иконка IziBox в меню-баре → **«Выход»**.
- Чтобы **запустить снова**: двойной клик по `run_macos.command`.

## Где хранятся данные

Все данные создаются рядом с приложением: `backend/data/users/<ваш_логин>/`. База зашифрована, в облако ничего не отправляется.

## Обновление

Скачайте новую версию (Code → Download ZIP) и распакуйте поверх старой папки. Ваши данные сохранятся (они в `backend/data/`).
